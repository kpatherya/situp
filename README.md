# SIT-UP: Integrated Posture Detection Research Prototype

SIT-UP is a research prototype for posture monitoring and intervention ideas
using side/front video processing, live data streaming, and optional feedback
actuation experiments.

Project metadata: [CONTRIBUTING.md](CONTRIBUTING.md) · [DATA_POLICY.md](DATA_POLICY.md) · [CITATION.cff](CITATION.cff) · [LICENSE](LICENSE)

## Repository Layout

- `front/`: front-camera detection experiments.
- `side/`: side-camera logging and video-generation scripts.
- `stream/`: data streaming and multi-camera orchestration scripts.
- `analysis/`: analysis and plotting scripts for posture logs.
- `vibrate/`: phone vibration notification experiments.
- `logs/`: anonymized sample logs and schema notes only.
- `questionnaire/`: study templates (raw participant responses are not tracked).

## Quick Start

1. Create and activate a Python environment.
2. Install dependencies.
3. Run one capture or detector script.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python side/side-logging.py
```

To run front-view detection, download the MediaPipe pose landmarker model and
place it under a local `models/` directory as required by the script.

## Data and Privacy

This repository stores only anonymized sample posture logs for reproducibility.
Raw participant data and identifiable responses should remain private and must
not be committed.

See [DATA_POLICY.md](DATA_POLICY.md) for consent, anonymization, retention, and
redaction rules.

## Expected Outputs

- Side/front video artifacts in local output folders.
- CSV posture logs generated during local runs.
- Analysis charts generated by scripts in `analysis/`.

## Research Status

This project is a prototype and is not a medical device.
